# Sumit Rodagai – Portfolio

A personal developer portfolio showcasing skills, projects, education, and contact information.

## 🚀 Live Demo

Deployed on [Vercel](https://vercel.com) – check the Vercel dashboard for the live URL after deployment.

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Font Awesome 6.5.1 (CDN)
- Fully responsive design

## 📁 Project Structure

```
my-portfolio/
├── index.html       # Main portfolio page (single-page app)
├── vercel.json      # Vercel deployment configuration
└── README.md        # Project documentation
```

## ▲ Deploy to Vercel

### Option 1 – Vercel Dashboard (Recommended)
1. Push this repository to GitHub
2. Go to [vercel.com](https://vercel.com) and sign in
3. Click **"Add New Project"** → Import your GitHub repo
4. Vercel will auto-detect it as a static site — click **"Deploy"**
5. Your portfolio will be live in seconds!

### Option 2 – Vercel CLI
```bash
npm install -g vercel
vercel login
vercel --prod
```
